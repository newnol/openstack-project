
## Report ownership

- Infra / Integration Lead: environment, installation, Module 1, final merge.
- Network / Compute Lead: Modules 2–3 and topology explanation.
- Storage / Automation Lead: Modules 4–5, Heat and cloud-init.

## Required report context

Document:

- Ubuntu version, vCPU, RAM, disk and swap
- DevStack branch and commit
- Heat and Swift enablement
- Why Ubuntu 24.04 was used although the assignment mentions 22.04
- Every command or script needed to reproduce each module
- Security-group rules, port mappings, floating IPs and guest routing
- Failure modes and troubleshooting performed

Use `diagrams/` for source diagrams and `screenshots/` only for selected final-report images; keep complete raw evidence in each module directory.
